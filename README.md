**Update 2.x is here!**

This mod adds a highly customizable and very lightweight HUD to your game.

### Features
* **Minimalistic Info**: Displays XYZ coordinates, FPS, and World Days.
* **Optimization**: Minimal impact on performance, perfect for low-end devices or large modpacks.
* **Easy Access**: Open the settings menu using the **'X'** key (default) or via the 'M' button in the Escape menu.

### Customization
You can fully customize the HUD to fit your needs:
* **Toggle Elements**: Disable any HUD element you don't need.
* **Color Selection**: Change labels and values colors separately.
* **Positioning**: Drag elements to any position on your screen.
